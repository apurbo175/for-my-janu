# For Mim ♡ — anniversary scrapbook website

This is a full-screen, click-through website inspired by your screenshots. Each page is a separate interface, with NEXT/BACK buttons; it is not a long scrolling page.

## Add photos
Put your own pictures in the `photos` folder and name them `photo1.jpg` through `photo6.jpg`. The placeholders will automatically be replaced by the matching images. Keep the photos folder next to `index.html`.

Edit text and colors in `index.html`. Search for `screen1`, `screen2`, etc. to find each page.

Requested details included:
- “HAPPY ANNIVERSARY” (no anniversary number/year)
- “DECADE OF TOGETHERNESS”
- Calendar highlights November 3, 2026

## Publish free using GitHub Pages
1. Sign in at https://github.com/
2. Create a **Public** repository called `for-mim`.
3. Upload `index.html` and the `photos` folder.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Once it deploys, GitHub shows a link similar to `https://YOUR-USERNAME.github.io/for-mim/`.
7. Test the link on your phone, then send it to Mim.

A public GitHub Pages site is accessible to anyone, so only upload photos you are comfortable making public.
